## 1. 这一格到底在演什么

一句话：**求助者最亲近的那个人，在没有任何人通知他的情况下，被系统主动找到。**

所以家属端的戏剧任务不是"展示一个来电界面"，而是三件事：

1. **手机原本是安静的** —— 待机时它只是一台锁屏手机，证明"没有人手动打电话给他"；
2. **响铃是被系统逼出来的** —— 机构超时未确认 → 系统自动外呼，与宫格②的自动升级横幅同帧发生；
3. **他必须给出一个动作** —— 联系他 / 赶过去 / 接不上（接不上时系统继续找人，链条不断）。

第 3 点是本模块相对骨架版本的**主要增量**。骨架版只做到"显示三个按钮"，细化版补齐了：
选择后的回执、选择之后的后续状态、以及"接不上"时**自动转呼下一位登记联系人**的兜底。

## 2. 阶段 × 状态矩阵（render 的完整分支表）

| 阶段 | 模块内部态 | 屏幕上是什么 | 角标 / 颜色 |
|---|---|---|---|
| `IDLE` | — | 锁屏：大时钟 + 日期 + 「已登记为 XX 的紧急联系人」「紧急来电可穿透静音」 | `待机` / 灰 |
| `SOS_TRIGGERED` | — | 同上（家属不应该提前知道，保持安静） | `待机` / 灰 |
| `INSTITUTION_ALERT` | — | 同上 | `待机` / 灰 |
| `AUTO_ESCALATE` | `registered=false` | 整格「无登记信息 / 本机未被呼出 / 已自动改派附近志愿者（王医生 · 0.8km）」 | `未呼叫` / 灰 |
| `AUTO_ESCALATE` | `ringing` | 来电界面：机构名 + 波形 + 呼出进度条 + 「最长响铃 15 秒后自动重试」 | `● 呼出中` / 红 |
| `AUTO_ESCALATE` | `answered` | 通话界面：**逐句**播报字幕 + 三个响应按钮 | `已接通` / 蓝 |
| `AUTO_ESCALATE` | 已选择 | 播报字幕 + **回执卡**（选择内容 + 记录时刻）+ 后续卡 | `已应答` / 绿 |
| `VIDEO_SESSION` | 未选择 | 通话界面保持（字幕继续走完）+ 三按钮 | `已接通` / 蓝 |
| `VIDEO_SESSION` | 已选择 | 回执卡 + 后续卡（见 §4.2） | `已应答` / 绿 |
| `ON_SITE` | 已登记 | 「志愿者已到达他身边」+ 回执 + 到场卡「现场已交接，你可以放心了」 | `已应答` / 绿 |
| `CLOSED` | 已登记 | 「本次事件已闭环」+ 「48 小时内会有专人回访」 | `已闭环` / 绿 |
| `ON_SITE` / `CLOSED` | `registered=false` | 未登记分支（同 `AUTO_ESCALATE` 一行） | `未呼叫` / 灰 |

> 兜底：任何阶段若 `D.user.registered === false`，本机一律走「未登记分支」——**这一格从头到尾不该被呼叫**。

### 2.1 内部态机（只在事件回调里改）

```
idle ──escalate:auto──> ringing ──timer:tick 到点──> answered ──点击选项──> answered + choice
                                └── 阶段推进（演示太快）──────────┘
reset ──────────────────────────────────────────────> idle
```

`choice ∈ { call, goto, unreachable, null }`，`reassigned = (choice === 'unreachable' && 存在下一位联系人)`。

## 4. 文案表（可直接打磨，全部集中在函数里）

### 4.1 系统语音播报（3 句，逐句点亮 + 逐句播报）

| # | 文案 | 播报时长基准 |
|---|---|---|
| 1 | 您好，这里是{机构名}。 | ≥1.4s |
| 2 | 您登记的家人{求助者名}刚刚发起了紧急求助。 | ≥1.4s |
| 3 | 当前位置在{地址}，请尽快联系他，或直接赶过去。 | ≥1.4s |

时长按 `字符数 × 150ms` 估算，钳在 1.4s ~ 3.0s 之间（`OFFSETS` 累计表）。

### 4.2 三个选项的后续卡

| choice | 回执之后的卡 |
|---|---|
| `call` 我现在就联系他 | 「通话中 · 请保持电话畅通」+「机构与志愿者已同步你的响应 / 如果他不接，请打开免提，让他听见你」 |
| `goto` 我马上赶过去 | 「前往中 · 已开启位置共享」+「你的位置会同步给求助者与志愿者 / 路上请保持手机畅通」 |
| `unreachable` 暂时无法接通 | 「本机已结束呼叫」+「系统已转呼下一位联系人：{下一位姓名}（{关系}）」+「附近志愿者同时赶往现场，流程不会中断」+ 反悔按钮 |

> 反悔按钮存在的理由：现场演示容易点错，点错之后整条线就废了。给它一个 1 秒的补救动作。

### 4.3 诚实边界（对评委）

每一屏底部都有小字：**「演示模拟外呼 · 不会拨打任何真实号码」**。
呼应 [需求.md](需求.md) §1.2 的红线，也提前回答了 §11.3 里"你们真的会打电话吗"。

## 5. 事件与数据读写（严格遵守契约）

| 方向 | 名称 | 说明 |
|---|---|---|
| **订阅** | `escalate:auto` | 唯一的外呼入口。未登记 → 只记日志不改状态；已登记 → 置 `ringing` |
| **订阅** | `timer:tick` | 唯一的时间来源。驱动 ①呼声进度 ②呼出→接通 ③字幕逐句点亮。**不额外起 `setInterval`**（契约 §4.3） |
| **订阅** | `stage:change` | 演示推进过快时把 `ringing` 收敛为 `answered`，避免视频阶段还在响铃 |
| **订阅** | `app:reset` | 清空会话态、字幕表、语音 |
| **发出** | `family:answer` `{ choice }` | **唯一对外事件**，payload 字段未扩展 |

读：`App.DATA`（`user` / `contacts` / `family` / `volunteers` / `institution`）、`App.CONFIG.FAMILY_CALL_SEC`、`App.state.stage|elapsedMs`。
写：只写 `#family-badge`（经 `App.setBadge`）与 `#family-screen`。

**未新增任何事件、未新增任何 CONFIG 字段、未新增任何 DOM id（屏幕内的 `id` 均为局部元素，带 `f-` 前缀，不与全局冲突）。**

### 5.1 建议框架负责人评估的三项（**我没有擅自改**）

1. **【阻塞级 BUG】`core.state.js` 的 `App.delegate` 每个 role 只生效第一次调用。**

   ```js
   App.delegate = function (role, selector, eventName, handler) {
     var sc = App.el(role + '-screen');
     if (!sc || sc.__delegated) return;        // ← 第二次起直接 return
     sc.__delegated = true;
     sc.addEventListener('click', function (ev) {
       var hit = ev.target.closest(selector);  // ← 只用得到第一次的 selector
       if (hit && sc.contains(hit)) handler(hit, ev);   // ← 只用得到第一次的 handler
     });
   };
   ```

   后果（**影响全部四个模块，不只家属端**）：
   - `ui.family.js`：只有「我现在就联系他」能点，「我马上赶过去」「暂时无法接通」点了没反应；
   - `ui.volunteer.js`：只有「立即响应」能点，「开始视频疏导」「我已到达现场」「填写处置记录」全部失效；
   - `ui.user.js`：只有求救按钮能点，「拨打 110 / 120」失效。

   修法（二选一，由框架负责人定）：
   - **A（推荐）**：改成按 selector 分组注册，去掉 `__delegated` 守卫——
     `(sc.__delegates = sc.__delegates || []).push({ selector, handler })`，单个监听里遍历该数组；
   - **B**：保持现状，约定「一个 role 只能调一次 delegate」，把多个按钮写成逗号选择器。

   **本模块已按 B 规避**：四个按钮合并成一次
   `App.delegate('family', '#btn-f-call, #btn-f-goto, #btn-f-no, #btn-f-undo', ...)`，在回调里按 `hit.id` 分派。
   所以家属端现在四个按钮**都真的能点**，不需要等 core 修。（见 §6.7）

2. **新增事件 `family:reassign`**（payload `{ from, to }`）
   用途：`unreachable` 转呼下一位联系人时，让宫格②的派单列表也能划掉第一个人、点亮第二个人。
   现状替代：只用 `App.log()` 记一条时间线，宫格②看不到。

3. **`boot.js` 的 `HOLD.AUTO_ESCALATE` 由 3000ms 调整为 6000ms**
   现状：家属外呼全屏画面只有 3 秒，字幕还没点亮第二句就切到视频阶段了。
   本模块已做兼容（字幕在 `VIDEO_SESSION` 里继续走完），但 6 秒的观感明显更好。

## 6. 实现要点（踩过的坑，写给后续维护的人）

1. **不要用 `App.render('family')` 刷新倒计时和字幕。**
   render 会重写 `innerHTML`，把动画状态清空。节奏类更新一律走 `querySelector` + 改 `style/classList`（`paintRing` / `paintLines`）。
   唯一的例外是"接通"这一次翻转 —— 它改变的是结构，必须整屏重绘。

2. **字幕进度必须能"重绘后复原"。**
   `lineCardHTML(count)` 会把已点亮的句子直接渲染成 `.on`，所以任何一次 `stage:change` 触发重绘后，进度都不会倒退。这是字幕能跨阶段连续播放的前提。

3. **`App.delegate` 绑在容器上，容器永不重建。**
   按钮反复销毁重建也不丢事件；但**不要**给按钮直接 `addEventListener`。

4. **`escalate:auto` 里要兜底开表。**
   `core.state.js` 只在进入 `SOS_TRIGGERED` 时启动全局 ticker。演示者若用 `App.jump('AUTO_ESCALATE')` 自测，ticker 没开、`timer:tick` 不会来，本模块会永远停在"呼出中"。所以外呼前判断 `App.state.startedAt`，为空则调用公开 API `App.startTicker()`。

5. **语音解锁。**
   Chrome 要求先有一次用户交互。`feature.speech.js` 已处理，本模块只管在"接通"和"每一句"两个时点调用 `App.speak(text, { interrupt: true })`，点击任一选项时 `App.speakStop()`。

6. **`T` 延迟构建。**
   播报文案在第一次 render 时才算，避免在脚本加载期就把 `D.user.name` 固化；`app:reset` 时置空，现场改 `data.demo.js` 后重置即生效。

7. **事件委托只能调一次（见 §5.1 第 1 条）。**
   四个按钮合并成一次 `App.delegate` 调用，回调里 `ACTIONS[hit.id]` 分派。
   若框架负责人日后修好 `App.delegate`，这段可以拆回四次调用，行为不变。

## 7. 自测：`tools/family-smoke.js`

不想开浏览器时，用仓库里的自测脚本跑一遍（Node，零依赖）：

```bash
node tools/family-smoke.js .      # 在仓库根目录执行
```

它用一个最小 DOM 桩把 `data.demo.js` → `core.state.js` → `core.timeline.js` → `feature.speech.js` → `ui.family.js`
按 `index.html` 的顺序真加载进来，然后用可控时钟驱动 `timer:tick`，逐个断言本文档 §2 的每个分支。

**当前结果：57 项全部通过。** 覆盖：

- 五个阶段的锁屏静默行为（IDLE / SOS / 机构告警都不该有来电）
- 自动外呼 → 呼出中 → 自动接通 的状态翻转与角标颜色
- 逐句字幕按 200ms 心跳推进、播报与字幕同源、重绘后不倒退
- 四个按钮的事件委托（这一项当初就是靠它揪出的 `App.delegate` bug）
- 三个响应选项各自的回执与后续卡、`unreachable` 的转呼与反悔
- `registered = false` 的未登记分支（含"整格无来电界面""不播报"）
- 跨阶段（AUTO_ESCALATE → VIDEO_SESSION → ON_SITE → CLOSED）状态保持
- 重置无残留、可重复跑第二遍

> 这个脚本只读不改，可以直接留在 `tools/` 里；C 每次改完 `ui.family.js` 跑一次即可，
> 也可以拷一份改掉最后两行 `load()` 去自测别人的模块。
